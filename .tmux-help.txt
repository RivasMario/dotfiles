  PREFIX = Ctrl+a  OR  ` (backtick)           press q to close

  PANES
    v  OR  -      Split right (vertical)
    h  OR  |      Split down (horizontal)
    f             Toggle full-screen zoom
    Alt+Arrow     Jump to pane (no prefix needed)
    Prefix+Arrow  Resize pane
    x             Kill pane

  WINDOWS
    c             New window
    ,             Rename window
    n / p         Next / previous window
    1-9           Jump to window by number
    w             Visual window picker
    &             Kill window

  SESSIONS
    s             List/switch sessions
    d             Detach (session keeps running background)
    
  SHELL ALIASES
    tm            New session
    tl            List sessions
    ta            Attach to session

  COPY MODE
    [             Enter scroll/copy mode
    v             Start selection
    y             Copy
    ]             Paste
    q             Exit copy mode

  OTHER
    r             Reload config
    ?             This help (opens in new window)
