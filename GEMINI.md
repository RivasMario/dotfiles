# Gemini / Antigravity - Dotfiles Workspace Guide

@./AGENTS.md

## Gemini CLI & Antigravity Specifics
- Global customizations live in `~/.gemini/config/` (agy) and `~/.gemini/` (Gemini CLI); both are machine-local, not tracked here.
- Skills: shared ones in `skills/`; Gemini-only or Gemini-specific overrides in `.gemini/skills/`.
- Caveman installs as an agy extension (`agy extensions install https://github.com/JuliusBrussee/caveman`).
- Claude Code shares this repo. Put shared rules in `AGENTS.md`, not here.
